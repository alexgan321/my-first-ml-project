# Мой первый проект машинного обучения (ML)
Практический проект по созданию и обучению предсказательной модели линейной регрессии.

Что было сделано:
Изучены основы синтаксиса языка Python и базовой математики алгоритмов.
Освоена аналитика и работа с табличными структурами данных через библиотеку Pandas.
Построена модель ИИ на базе библиотеки Scikit-learn для решения задачи регрессии.
Получен прогноз: модель успешно выявила закономерности в данных и рассчитала точную рыночную стоимость для новой квартиры площадью 80 кв.м. (16.00 млн руб.).
Стек технологий:
Python, Google Colab, NumPy, Pandas, Scikit-learn, GitHub Desktop.
