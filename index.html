Перевод из:
1.0x
При клике слово озвучивается повторно!
Инструкция по работе с программой x
  1. Составление списков (Важно): Первая строка в вашем .txt файле обязательно должна быть служебной на русском языке. Программа её не переводит. Со второй строки пишите чистые иностранные слова (для Интернета) или готовые пары вида Слово - Перевод (для Списка).
  2. Загрузка урока: Выберите язык в меню программы, нажмите кнопку «Открыть список слов» и укажите ваш .txt файл. При готовности кнопка станет зелёной.
  3. Режим обучения: Нажимайте кнопку «Следующее слово». По окончании списка слов кнопка снова станет белой.
  4. Повтор звука: Кликните по любой строчке в списке сохранённых строк внизу — программа заново произнесёт это слово.
  5. Вы можете переводить иностранные слова и фразы используя два списка слов: 1-й список содержит только иностранные слова; 2-ой список содержит: Слово - Перевод, что позволит прослушивать слова с вашим переводом.
  6. Для переключения между списками слов надо выбрать: "Перевод из: Интернета" - 1 Список или "Перевод из: Списка" - 2 Список!
